# NZGE-Unofficial

NZGE-Unofficial is an unofficial NeoForge port of [NineZero's Gun Expansion](https://github.com/zaeonNineZero/NineZero-Gun-Expansion) by zaeonNineZero, for [createmeow's port of MrCrayfish's Gun Mod](https://github.com/createmeow/MrCrayfishGunMod/tree/1.21.1). It adds weapons and attachments with a simple Minecraft-inspired style, giving each weapon a distinctive look while fitting alongside CGM's original arsenal.

### Features

- 21 weapons, with additional model variants.
- Medium Bullets for several of the rifles.
- 19 attachments, including sights, barrels, stocks, a grip and a bipod.
- Workbench recipes for use in survival mode.

Download the ready-to-use JAR from [Releases](https://github.com/Swamp-Derrick/NineZero-Gun-Expansion-1.21.1NF/releases/latest) and place it in your `mods` folder alongside the required dependencies.

**Requires:** Minecraft 1.21.1, NeoForge 21.1.228+ (21.1.x), Java 21, CGM UnUnofficial 1.4.4 and Framework 0.13.11 for NeoForge.
